:::note
The `uṇādi` suffixes ("`u` and the rest") are the primary suffixes not covered by the `kita` rules of the previous chapter: `kāru` ("artisan") from `√kara` + `u`, `bhikkhu` from `√bhikkha` + `u`, and a long tail of words whose derivation the grammar records one by one. The Chaṭṭha Saṅgāyana edition counts this chapter as the sixth section of the `kibbidhāna` chapter; its last line closes the whole Kaccāyana.

:::

:::note[What the uṇādi rules do]
The chapter first states the scope of the primary suffixes (§624–§626) and then records, suffix by suffix and word by word, the formations the earlier rules do not reach.

```mermaid
flowchart LR
  U(["uṇādi: the remaining primary suffixes"]) --> S["scope: kita for the agent §624<br/>kicca, tta and kha for the impersonal and the object §625–§626"]
  U --> A["ṇu, ṇvu, tu, ṇa and the rest, by time §650–§652, §654–§655, §671<br/>kāru, vāyu, bhottu, hetu"]
  U --> B["mana, tha, la, ya and the rest §627–§636<br/>khemo, samatho, kalyaṃ"]
  U --> C["ta, ṇitta, tti and ti §656–§658<br/>chattaṃ, metti"]
  U --> D["words formed one by one §638–§649, §659–§673<br/>sunakho, yuvā, khandho, cīvaraṃ, manusso"]
  U --> E["counting: kkhattuṃ §646<br/>ekakkhattuṃ, dvikkhattuṃ"]
```

:::

### §625 (605): Bhāvakammesu kiccattakkhatthā (the `kicca` suffixes, `tta` and the `kha`-type suffixes denote `bhāva` and `kamma`) :badge[utsarga]{variant=success}

| ------ | ------ | ------ | --------- | ---------- | ------ | ------- |
|        | (dhātūhi) |     | (paccayā honti) | kicca\|tta\|khatthā | | bhāvakammesu |
|        | (after a root) | | (suffixes are used) | the `kicca` suffixes \| `tta` \| those with the sense of `kha` | | in the senses of the action itself and of the object |

The heading follows the CST sutta list and the Rūpasiddhi, `kiccattakkhatthā`; the CST's vutti section prints `kiccatta khatthā` as two words.

:::

> Bhāvakammaiccetesvatthesu kicca tta khattha iccete paccayā honti.

> Upasampādetabbaṃ upasampādanīyaṃ bhavatā, sayitabbaṃ bhavatā, kattabbaṃ bhavatā[^1], bhottabbo odano bhavatā, asitabbaṃ bhojanaṃ bhavatā, asitaṃ bhavatā, sayitaṃ bhavatā, pacitaṃ bhavatā, asitaṃ asanaṃ bhavatā, sayitaṃ sayanaṃ bhavatā, pacito odano bhavatā, kiñcissayo, īsassayo, dussayo, sussayo bhavatā.

| 🚻①⨀(√asa + tabba) | asitabbaṃ bhojanaṃ bhavatā | the food is to be eaten by you (`kamma`) |
| 🚻①⨀(√asa + tta) | asitaṃ bhavatā | eating was done by you (`bhāva`) |
| 🚻①⨀(√sī + tta) | sayitaṃ bhavatā | lying down was done by you (`bhāva`) |

| 🚻①⨀(√asa + tta) | asitaṃ asanaṃ bhavatā | the food was eaten by you (`kamma`) |
| 🚻①⨀(√sī + tta) | sayitaṃ sayanaṃ bhavatā | the bed was lain on by you (`kamma`) |
| 🚹①⨀(√paca + tta) | pacito odano bhavatā | the rice was cooked by you (`kamma`) |

| 🚹①⨀(du + √sī + kha) | dussayo | lying is hard; hard to lie on |
| 🚹①⨀(su + √sī + kha) | sussayo bhavatā | lying is easy for you |

### §626 (634): Kammani dutiyāya tto (`tta` denotes the agent when the object stands in the second form) :badge[apavada]{variant=success}

:::note[Analysis]

| option | before | from   | operation | to         | after  | context |
| ------ | ------ | ------ | --------- | ---------- | ------ | ------- |
|        |        | (dhātūhi) | (paccayo hoti) | tto | | kammani dutiyāya (kattari) |
|        |        | (after a root) | (a suffix is used) | `tta` | | when the object is in ② (denoting the agent) |

:::

> Kammani iccetasmiṃ atthe dutiyāyaṃ vibhattiyaṃ kattari ttapaccayo hoti.

> Dānaṃ dinno devadatto, sīlaṃ rakkhito devadatto, bhattaṃ bhutto devadatto, garuṃ upāsito devadatto.

When the object (`kamma`) is in the second inflection ②, the suffix `tta` is used in the sense of the agent.

### §627 (652): Khyādīhi mana ma ca to vā (`mana` after `khi` and the like; and optionally `t` for its `m`) :badge[apavada]{variant=success}

:::note[Analysis]

| option | before | from   | operation | to         | after  | context |
| ------ | ------ | ------ | --------- | ---------- | ------ | ------- |
|        | khyādīhi | (dhātūhi) | (paccayo hoti) | mana | | |
| ca vā  |        | massa  | (ādeso)   | to         |        |         |
|        | after `khi` and the like | (roots) | (a suffix is used) | `mana` | | |
| and, optionally | | the `m` [of `mana`] | (replaced by) | `t` | | |

The heading follows the CST sutta list and the Rūpasiddhi, `mana`; the CST's vutti section prints `māna`.

:::

> Khi bhī su ru hu vā dhū hi lū pī adaiccevamādīhi dhātūhi mana paccayo hoti, massa ca to hoti vā.

> Khīyanti upaddavā etthāti khemo, bhāyitabboti bhemo[^3], bhāyanti etasmāti vā bhemo, raṃsiyo abhissavetīti somo, ravati gacchatīti romo, huvati juhvati etenāti homo, paṭilomavasena vāti gacchatīti vāmo, lāmakavasena vāti gacchati pavattatīti vā vāmo, dhunāti kampatīti dhūmo, seṭṭhabhāvena hinoti pavattati cittaṃ etasminti hemo, lunitabboti lomo, maṃsacammāni lunāti chindatīti vā lomo, piyanaṃ pemo, piyāyitabboti vā pemo, sukhadukkhaṃ adati bhakkhatīti attā, jātijarāmaraṇādīhi adīyate bhakkhīyateti vā attā, ātumā.

| 🚹①⨀(√vā + mana) | vāmo | "it goes (`vāti`) the contrary way", or "the inferior way": left; contrary |
| 🚹①⨀(√dhū + mana) | dhūmo | "it shakes (`dhunāti`), it trembles": smoke |

### §628 (653): Samādīhi tha mā (`tha` and `ma` after `samu` and the like) :badge[apavada]{variant=success}

:::note[Analysis]

| option | before | from   | operation | to         | after  | context |
| ------ | ------ | ------ | --------- | ---------- | ------ | ------- |
|        | samādīhi | (dhātūhi) | (paccayā honti) | tha\|mā | | |
|        | after `samu` and the like | (roots) | (suffixes are used) | `tha` \| `ma` | | |

:::

> Samu damu dara raha du hi si bhī dā yā sā ṭhābhasaiccevamādīhi dhātūhi tha ma paccayā honti.

> Sametīti samatho, damatīti damatho, damanaṃ vā damatho, damitabboti vā damatho, daratīti daratho, jiṇṇabhāvaṃ rahissati gaṇhissatīti ratho, dabbasambhāre rahati gaṇhātīti vā ratho, davati gacchatīti dumo, davati vuddhi viruḷhi gacchati pavattatīti uddhaṃ vā dumo, pathavīpabbatādīsu gacchati patatīti himo, kammavācāya bandhati etthāti sīmā[^4]. Bandhitabbāti vā sīmā. Bhāyanti etasmāti bhīmo, satte avakhaṇḍenti nivārenti etenāti dāmo, mūsikādīhi khādīyati avakhaṇḍīyatīti vā dāmo, yāti gacchatīti yāmo, paresaṃ cittaṃ gaṇhituṃ samatthetīti sāmo, tiṭṭhanti etenāti thāmo, bhasati bhasmīkarīyatīti bhasmā.

After the roots `samu`, `damu`, `dara`, `raha`, `du`, `hi`, `si`, `bhī`, `dā`, `yā`, `sā`, `ṭhā`, `bhasa` and the like, the suffixes `tha` and `ma` are used.

:::tip[Examples]

| lemma | inflected | meaning |
| ----- | --------- | ------- |
| 🚹①⨀(√sama + tha) | samatho | "it calms (`sameti`)": calm, tranquillity |
| 🚹①⨀(√dama + tha) | damatho | "it tames (`damati`)", "taming", or "to be tamed": taming, self-control |
| 🚹①⨀(√dara + tha) | daratho | "it splits (`darati`)": distress |
| 🚹①⨀(√raha + tha) | ratho | "it will take on (`rahissati`) decay", or "it holds the materials": a chariot |
| 🚹①⨀(√du + ma) | dumo | "it goes (`davati`)", or "it goes upward in growth": a tree |
| 🚹①⨀(√hi + ma) | himo | "it goes, falls on the earth, mountains and the like": snow, frost |
| 🚺①⨀(√si + ma) | sīmā | "one binds (`bandhati`) here by the formal proclamation", or "to be bound": a boundary |
| 🚹①⨀(√bhī + ma) | bhīmo | "they are afraid (`bhāyanti`) of it": terrible |

### §672 (682): Kuṭādīhi ṭho (`ṭha` after `kuṭa` and the like) :badge[apavada]{variant=success}

:::note[Analysis]

| option | before | from   | operation | to         | after  | context |

> Kuṭa kusa kaṭaiccevamādīhi dhātūhi, pāṭipadikehi ca ṭhapaccayo hoti[^50].

### §673 (683): Manu pūra suṇādīhi ussa nusisā (`ussa`, `nusa`, `isa` after `manu`, `pūra`, `suṇa` and the like) :badge[apavada]{variant=success}

:::note[Analysis]

| option | before | from   | operation | to         | after  | context |
| ------ | ------ | ------ | --------- | ---------- | ------ | ------- |
|        | manu pūra suṇādīhi (dhātūhi pāṭipadikehi ca) | | (paccayā honti) | ussa\|nusa\|isā | | (puna nippajjante) |
|        | after `manu`, `pūra`, `suṇa` and the like (roots, and nominal lemmas) | | (suffixes are added) | `ussa`\|`nusa`\|`isa` | | (then formed as usage has them) |

:::

> Manu pūra suṇa kusu[^51] ila ala maha si ki iccevamādīhi dhātūhi, pāṭipadikehi ca ussa[^52] nusa isa iccete paccayā honti, puna nippajjante.

> Kusalākusale dhamme manati jānātīti manusso, mānuso. Kāraṇā kāraṇaṃ manati jānātīti vā manusso, mānuso[^53]. Atthānatthaṃ manati jānātīti vā manusso, mānuso.

> Mātāpitūnaṃ hadayaṃ pūretīti puriso, attano manorathaṃ pūretīti vā puriso, pūretīti vā poso, sasurehi suṇitabbā hiṃsitabbāti suṇisā, dvinnaṃ jānānaṃ kulasantānaṃ karotīti vā suṇisā, kucchitabbanti karīsaṃ, gabbhaṃ vimocetīti suriso[^54], tamandhakāravidhamanena sattānaṃ bhayaṃ surati hiṃsatīti sūriyo, rogaṃ hiṃsatīti sirīso, ilati kampatīti illiso, taṇhāya dubbalo hutvā ilati kampatīti vā illiso[^55], pāpakaraṇe alati samatthetīti alaso, mahitabbo pūjetabboti mahiso, sīyati bandhīyatīti sīsaṃ, kitabbaṃ hiṃsitabbanti kisaṃ, iccevamādi.

After the roots `manu` ("know"), `pūra` ("fill"), `suṇa` ("hurt"), `kusu` ("despise"), `ila` ("shake"), `ala` ("be able"), `maha` ("honour"), `si` ("bind"), `ki` ("hurt") and the like, and after nominal lemmas, the suffixes `ussa`, `nusa` and `isa` are added; [the words] are then formed.
