Companion to the cleaned reading edition in this folder. The base text is the proofread transcription (*Thiab Malai 1997 Thesis.md* and *Thiab Malai 1997 Thesis vol.2.md*), which was checked page by page against the scanned PDFs. This file lists every change made to the wording of that text, and every formatting change that affects more than markup.

## Scope

- **Corrected:** typing errors in the author’s English, and clear slips in names, references, headings and quoted Pāli. A slip counts as clear only where the right form is certain, usually because the same word is spelt correctly nearby or in the cited source line.
- **Not touched:** reported variant readings (for example “B<sub>1</sub> reads X for Y”), which are reproduced exactly as typed. Readings that could be deliberate are also left alone, and so are the items under [Queried](#3-queried--left-as-typed).
- **Pāli slips:** only those found during proofreading and the checks for this edition are corrected. The quotations have not been re-collated against the printed editions.
- **Locations:** “p.” gives the typescript page, which also appears as a hidden `<!-- p. N -->` marker in each file. “n.” gives a footnote label in that file, for example n. 3-12 = `[^3-12]`.

## 2. Formatting

### 2.1 Applied throughout (not listed individually)

- **Files:** one file per *kappa* (`chapter1.md`–`chapter8.md`), plus `introduction.md` and `front-matter.md` (title page, certificate, declaration, contents, acknowledgement, abbreviations and bibliography). The Contents table links to each file.
- **Page breaks:** paragraphs, verse quotations and tables that run across a typescript page are joined. The page marker is placed where the break fell, and repeated table header rows are dropped. Words hyphenated across a page break are rejoined (see 2.2).
- **Subscripts and superscripts:** `B~1~` / `S^a^` notation is converted to HTML: B<sub>1</sub>, S<sup>a</sup>, PED homonym numbers such as *phāla*<sup>1</sup>.
- **Verses:** each verse line ends with `<br>` so that the lineation survives rendering. Multi-line prose blocks (the opening *Namo tassa* formula and colophons) are treated the same way.
- **Footnotes:** the definitions are gathered at the end of each file. Labels keep the typescript note numbers. In chapters with several Notes sections (I, II, VI, VII) the label is prefixed by the section: `[^2-14]` = note 14 belonging to Notes II.2. Many Markdown viewers display footnotes renumbered 1, 2, 3 …; the label in the file is the typescript number. Where the typescript refers to the same note twice, both references point to one definition.
- **Headings:** chapter titles are given as “I. Sandhi-kappa” … “VIII. Uṇādi-kappa”. Front-matter headings are in title case. Rule headings stay in bold, for example **[1] Kattari kit.** 626.
- **Italics:** a rule-based pass italicises Pāli words and phrases inside English sentences, and titles of works. Rule text, *vutti*, verses and quoted passages stay roman. The pass is heuristic, so occasional misses are likely. A Pāli form that is also an English word (e.g. *go*, *bo*, *co*) may stay roman, and a rare English or proper name may be italicised.
- **Quotation marks:** where the pairing is clear, mismatched pairs are made to match (for example an opening single mark closed by a double one), and missing closing marks after headwords are supplied. Each case is listed in 2.2. Nested and unclosed quotations whose extent is unclear are left as typed (see section 3).
- **Removed:** scan notes and transcription comments from the proofread files. Also removed: the duplicate scan of p. 795 at vol. 2 PDF p. 148.
- **Lacuna:** printed p. 629 is missing from the scanned copy (the scan repeats p. 795 in its place). A bracketed note marks the gap in `chapter6.md`: the text from the rest of rule 16 to the start of rule 19 in Ākhyāta-kappa, *kaṇḍa* 3.
