## Napuṃsakaliṅga (Neuter nouns)

> Atha napuṃsakaliṅgāni vuccante.

Now the neuter lemmas are stated.

## `citta`

:::note[Inflection table of `citta`]

The forms of `citta` (mind), 🚻(citta), derived in rules 195–196; each form links to the rule that derives it.

| | ⨀ | ⨂ |
| --- | --- | --- |
| ① | [cittaṃ](#r195) | [cittā, cittāni](#r196) |
| ⓪ | [citta](#r196) | [cittā, cittāni](#r196) |
| ② | [cittaṃ](#r196) | [citte, cittāni](#r196) |

The rest as `purisa`.

:::

> A kāranto napuṃsakaliṅgo citta saddo.

The neuter lemma ending in `a` is the word `citta` ("mind").

> Pure viya syā dyuppatti, ‘‘citta si’’ itīdha –

As before, `si` and the rest arise; here, in `citta` + `si` —

> ‘‘Napuṃsakehi, ato nicca’’nti ca vattate.

“`napuṃsakehi`” ("after neuters") and “`ato niccaṃ`” ("always after `a`") also continue.

### 195 (§219): Siṃ (neuter `si` becomes `aṃ`) :badge[apavada]{variant=success}

:::tip[Kaccāyana]
<LinkCard title="§219 (195): Siṃ" href="/kaccayana/2-namakappa/4-catutthakanda#m219" description="neuter `si` becomes `aṃ`" />
:::

:::note[Analysis]

“`napuṃsakehi`” continues from [199 (§217): Yonaṃ ni napuṃsakehi](/rupasiddhi/2-namakanda/3-napumsakalinga#r199) and “`ato niccaṃ`” from [196 (§218): Ato niccaṃ](/rupasiddhi/2-namakanda/3-napumsakalinga#r196), both of which Buddhappiya states later on this page.

:::

> Si, aṃ iti dvipadamidaṃ. A kārantehi napuṃsakaliṅgehi parassa si vacanassa aṃ hoti niccaṃ. Saralopapakatibhāvādi, cittaṃ.

This is two words: `si` and `aṃ`. After neuter lemmas ending in `a`, the inflection `si` always becomes `aṃ`; with the vowel elision, the natural form (`pakatibhāva`) and the rest: `cittaṃ`.

:::tip[Derivation]

| →   | citt + (~~a~~ + aṃ)   | 67 (§83) |
| →   | **cittaṃ**            |      |

:::

> Bahuvacane ‘‘yonaṃ ni napuṃsakehī’’ti vattate.

In the plural, [199 (§217): Yonaṃ ni napuṃsakehi](/rupasiddhi/2-namakanda/3-napumsakalinga#r199) continues.

<a name="r196"></a>

### 196 (§218): Ato niccaṃ (always, after neuter `a`) :badge[apavada]{variant=success}

:::tip[Kaccāyana]
<LinkCard title="§218 (196): Ato niccaṃ" href="/kaccayana/2-namakappa/4-catutthakanda#m218" description="always, after neuter `a`" />
:::

> A kārantehi napuṃsakaliṅgehi yo naṃ niccaṃ ni hoti. ‘‘Sabbayonīnamāe’’ti ni ssa vā ā kāro. Aññattha ‘‘yosu kata’’iccādinā dīgho. Cittā cittāni.

After neuter lemmas ending in `a`, the `yo` inflections always become `ni`. By [§107 (69): Sabbayonīnamāe](/kaccayana/2-namakappa/1-pathamakanda#m107) the `ni` optionally becomes the letter `ā`; elsewhere there is lengthening by [§88 (147): Yosu katanikāralopesu dīghaṃ](/kaccayana/2-namakappa/1-pathamakanda#m88) and the rest: `cittā`, `cittāni`.

> Yonaṃ nibhāve cāette, siddhepi avisesato; \
> ‘‘Ato nicca’’nti ārambhā, āettaṃ kvacidevidha.

Although, once `yo` has become `ni`, the change to `ā` and `e` too would follow without distinction, \
because the rule `Ato niccaṃ` has been undertaken, the change to `ā` and `e` takes place here only in some places.[^53]

> Ālapane ga lopo. He citta, he cittā cittāni, dutiyāyaṃ ni ssa vikappenekāro. Cittaṃ, citte cittāni. Sesaṃ purisa saddena samaṃ.

In the vocative, `ga` is elided: `he citta`; `he cittā`, `he cittāni`. In the second form ②, the `ni` optionally becomes the letter `e`: `cittaṃ`; `citte`, `cittāni`. The rest is the same as for the word `purisa`.

:::tip[Derivation]

| →   | citta + (yo→ni)       | 196 (§218) |
| →   | citt + (a→ā) + ni     | 147 (§88) |
| →   | **cittāni**           |      |

|     | citta + yo (🚻①⨂)     | rule |
| --- | --------------------- | ---- |
| →   | citta + (yo→ni)       | 196 (§218) |
| →   | citta + (ni→ā)        | 69 (§107) |
| →   | citt + (~~a~~ + ā)    | 67 (§83) |
| →   | **cittā**             |      |

|     | citta + ga (🚻⓪⨀)     | rule |
| --- | --------------------- | ---- |
| →   | citta + ~~ga~~        | 74 (§220) |
| →   | **citta**          |      |

|     | citta + yo (🚻②⨂)     | rule |
| --- | --------------------- | ---- |
| →   | citta + (yo→ni)       | 196 (§218) |
| →   | citta + (ni→e)        | 69 (§107) |
| →   | citt + (~~a~~ + e)    | 67 (§83) |
| →   | **citte**             |      |

:::

> Evamaññānipi –

In the same way, others too —

> Puñña pāpa phala rūpa sādhanaṃ, \
> Sota ghāna sukha dukkha kāraṇaṃ; \
> Dāna sīla dhana jhāna locanaṃ, \
> Mūla kūla bala jālamaṅgalaṃ.

`puñña` (merit), `pāpa` (evil), `phala` (fruit), `rūpa` (form), `sādhana` (accomplishing); \
`sota` (ear), `ghāna` (nose), `sukha` (pleasure), `dukkha` (pain), `kāraṇa` (cause); \
`dāna` (giving), `sīla` (virtue), `dhana` (wealth), `jhāna` (absorption), `locana` (eye); \
`mūla` (root), `kūla` (bank), `bala` (strength), `jāla` (net), `maṅgala` (blessing).

> Naḷina liṅga mukha’ṅga jala’mbujaṃ, \
> Pulina dhañña hirañña padā’mataṃ; \
> Paduma vaṇṇa susāna vanā’yudhaṃ, \
> Hadaya cīvara vattha kuli’ndriyaṃ.

`naḷina` (lotus), `liṅga` (mark), `mukha` (face), `aṅga` (limb), `jala` (water), `ambuja` (lotus); \
`pulina` (sandbank), `dhañña` (grain), `hirañña` (gold), `pada` (foot; word), `amata` (the deathless); \
`paduma` (lotus), `vaṇṇa` (colour), `susāna` (cemetery), `vana` (forest), `āyudha` (weapon)[^54]; \
`hadaya` (heart), `cīvara` (robe), `vattha` (cloth), `kula` (family), `indriya` (faculty).

> Nayana vadana yāno’dāna sopāna pānaṃ, \
> Bhavana bhuvana lohā’lāta tuṇḍa’ṇḍa pīṭhaṃ; \
> Karaṇa maraṇa ñāṇā’rammaṇā’rañña tāṇaṃ, \
> Caraṇa nagara tīracchatta chiddo’dakāni –

`nayana` (eye), `vadana` (face), `yāna` (vehicle), `udāna` (utterance), `sopāna` (staircase), `pāna` (drink); \
`bhavana` (dwelling), `bhuvana` (world), `loha` (metal), `alāta` (firebrand), `tuṇḍa` (beak), `aṇḍa` (egg), `pīṭha` (seat); \
`karaṇa` (instrument), `maraṇa` (death), `ñāṇa` (knowledge), `ārammaṇa` (object), `arañña` (wilderness), `tāṇa` (shelter); \
`caraṇa` (foot; conduct), `nagara` (city), `tīra` (shore), `chatta` (parasol), `chidda` (hole), `udaka` (water) —

> Iccādīni.

and so on.

### 197 (§160): A kammantassa ca (and `a` for the final of `kamma` [before `nā`]) :badge[apavada]{variant=success}

:::tip[Kaccāyana]
<LinkCard title="§160 (197): A kammantassa ca" href="/kaccayana/2-namakappa/2-dutiyakanda#m160" description="and `a` for the final of `kamma` [before `nā`]" />
:::

:::note[Analysis]

“`vā`” continues from [143 (§158): Susmimā vā](/rupasiddhi/2-namakanda/1-pullinga#r143), and “`u`”, “`nāmhi`” and “`ca`” from [139 (§159): U nāmhi ca](/rupasiddhi/2-namakanda/1-pullinga#r139).

:::

> Kamma saddantassa u kāra a kārādesā honti vā nā mhi vibhattimhi. Anta ggahaṇena thāmaddhā dīnamantassapi u ttaṃ. Ca saddaggahaṇena yuva maghavā namantassa ā hoti kvaci nā su iccetesu. Kammunā kammanā kammena vā, kammehi kammebhi.

When the inflection `nā` follows, the final of the word `kamma` ("action") is optionally replaced by the letter `u` or the letter `a`. The mention of `anta` ("final") makes the final of `thāma` ("strength"), `addhā` ("path; time") and the like become `u` as well, and the mention of the word `ca` makes the final of `yuva` ("youth") and `maghava` ("Maghavā") become `ā` in some places (`kvaci`) before `nā` and `su`: `kammunā`, `kammanā` or `kammena`; `kammehi`, `kammebhi`.

> Sasmā su ‘‘u nāmhi cā’’ti ettha ca saddena puma kammathāma ntassa cukāro vā sasmā sūti u ttaṃ. Kammuno kammassa, kammānaṃ, kammunā kammā kammamhā kammasmā, kammehi kammebhi, kammuno kammassa, kammānaṃ.

Before `sa` and `smā`, the change to `u` comes from the word `ca` in [§159 (139): Unāmhi ca](/kaccayana/2-namakappa/2-dutiyakanda#m159), by which the final of `puma`, `kamma` and `thāma` optionally becomes the letter `u` before `sa` and `smā` as well: `kammuno`, `kammassa`; `kammānaṃ`; `kammunā`, `kammā`, `kammamhā`, `kammasmā`; `kammehi`, `kammebhi`; `kammuno`, `kammassa`; `kammānaṃ`.

> Smiṃ vacane ‘‘brahmato tu smiṃnī’’ti ettha tu saddena kvaci ni hoti. Kammani kamme kammamhi kammasmiṃ, kammesu.

In the inflection `smiṃ`, the word `tu` in [§197 (125): Brahmato tu smiṃ ni](/kaccayana/2-namakappa/3-tatiyakanda#m197) gives `ni` in some places: `kammani`, `kamme`, `kammamhi`, `kammasmiṃ`; `kammesu`.

> Evaṃ thāmunā thāmena thāmasā vā, thāmuno thāmassa, thāmunā thāmā. Addhunā, addhuno iccādi purimasamaṃ.

In the same way `thāmunā`, `thāmena` or `thāmasā`; `thāmuno`, `thāmassa`; `thāmunā`, `thāmā`; and `addhunā`, `addhuno` and so on, the same as the preceding.

### 198 (§125): Aṃ napuṃsake (`aṃ` for `ntu` before `si` in the neuter) :badge[apavada]{variant=success}

:::tip[Kaccāyana]
<LinkCard title="§125 (198): Aṃ napuṃsake" href="/kaccayana/2-namakappa/2-dutiyakanda#m125" description="`aṃ` for `ntu` before `si` in the neuter" />

:::note[Analysis]

“`savibhattissa`”, “`ntussa`” and “`simhi`” continue from [98 (§124): Ā simhi](/rupasiddhi/2-namakanda/1-pullinga#r98).

> Napuṃsake vattamānassa liṅgassa sambandhino ntu ppaccayassa savibhattissa aṃ hoti si mhi vibhattimhi. Guṇavaṃ cittaṃ.

When the inflection `si` follows, the suffix `ntu` belonging to a lemma that occurs in the neuter, together with its inflection, becomes `aṃ`: `guṇavaṃ cittaṃ` ("a virtuous mind").

> Yo mhi ‘‘ntussanto yosu cā’’ti a ttaṃ, i kāro ca. Guṇavanti, guṇavantāni, sesaṃ ñeyyaṃ.

> Gacchanta si, ‘‘simhi gacchantādīnaṃ ntasaddo a’’miti aṃ. Gacchaṃ gacchantaṃ, gacchantā gacchantāni.

In `gacchanta` + `si`, [§186 (107): Simhigacchantādīnaṃ ntasaddo aṃ](/kaccayana/2-namakappa/3-tatiyakanda#m186) gives `aṃ`: `gacchaṃ`, `gacchantaṃ` ("going"); `gacchantā`, `gacchantāni`.

## `assaddhā`

:::note[Inflection table of `assaddhā`]

The forms of `assaddhā` (faithless), 🚻(assaddhā), stated in the passage between rules 198 and 199, which has no rule of its own.

| | ⨀ | ⨂ |
| --- | --- | --- |
| ① | assaddhaṃ | assaddhā, assaddhāni |

The rest as `citta`.

The forms of `mukhanāsikā` (mouth and nose), 🚻(mukhanāsikā), which the same passage states; it has the singular only:

| | ⨀ | ⨂ |
| --- | --- | --- |
| ① | mukhanāsikaṃ | |
| ⓪ | mukhanāsika | |
| ② | mukhanāsikaṃ | |
| ③ | mukhanāsikena | |

:::

> Ā kāranto napuṃsakaliṅgo assaddhā saddo.

The neuter lemma ending in `ā` is the word `assaddhā` ("faithless").

> ‘‘Assaddhā’’iti ṭhite –

With `assaddhā` in place —

> ‘‘Samāsassā’’ti adhikicca ‘‘saro rasso napuṃsake’’ti samāsantassa rassattaṃ, samāsattā nāmabyapadeso, syā dyuppatti. Sesaṃ citta samaṃ.

With “`samāsassa`” ("of a compound") as the governing rule ([`adhikāra`](/introduction#types-of-suttas)), the final of the compound is shortened by [§342 (337): Saro rasso napuṃsake](/kaccayana/4-samasakappa#m342); because it is a compound, it is designated a noun (`nāmabyapadesa`), and `si` and the rest arise. The rest is the same as `citta`.

:::tip[Derivation]

|     | assaddhā + si (🚻①⨀)      | rule |
| --- | ------------------------- | ---- |
| →   | assaddh + (ā→a) + si      | 337 (§342) |
| →   | assaddha + (si→aṃ)        | 195 (§219) |
| →   | assaddh + (~~a~~ + aṃ)    | 67 (§83) |
| →   | **assaddhaṃ**             |      |

:::

> Assaddhaṃ kulaṃ, assaddhā assaddhāni kulāni iccādi.

`assaddhaṃ kulaṃ` ("a faithless family"); `assaddhā`, `assaddhāni kulāni`, and so on.

> Tathā mukhanāsikā saddo. Tassa dvandekattā sabbatthekavacanameva. Mukhanāsikaṃ, he mukhanāsika, mukhanāsikaṃ, mukhanāsikena iccādi.

So too the word `mukhanāsikā` ("mouth and nose"): because it is a `dvanda` compound taken as one (`dvandekatta`), it has the singular only throughout: `mukhanāsikaṃ`, `he mukhanāsika`, `mukhanāsikaṃ`, `mukhanāsikena` and so on.

> I kāranto napuṃsakaliṅgo aṭṭhi saddo.

### 199 (§217): Yonaṃ ni napuṃsakehi (`yo` becomes `ni` after neuters) :badge[apavada]{variant=success}

:::tip[Kaccāyana]
<LinkCard title="§217 (199): Yonaṃ ni napuṃsakehi" href="/kaccayana/2-namakappa/4-catutthakanda#m217" description="`yo` becomes `ni` after neuters" />
:::

> Napuṃsakaliṅgehi paresaṃ sabbesaṃ yonaṃ ni hoti vā.

After neuter lemmas, all the `yo` inflections that follow optionally become `ni`.[^55]

> Aṭṭhīni, aññattha niccaṃ yo lopo, dīgho ca, aṭṭhī, tathā he aṭṭhi, he aṭṭhī aṭṭhīni, aṭṭhiṃ, aṭṭhī aṭṭhīni, aṭṭhinā iccādi aggi saddasamaṃ.

`aṭṭhīni`; elsewhere `yo` is always elided, with lengthening: `aṭṭhī`. Likewise `he aṭṭhi`; `he aṭṭhī`, `he aṭṭhīni`; `aṭṭhiṃ`; `aṭṭhī`, `aṭṭhīni`; `aṭṭhinā`, and so on, the same as the word `aggi`.

> Evaṃ satthi dadhi vāri akkhi acchi acci iccādīni.

In the same way `satthi` (thigh), `dadhi` (curds), `vāri` (water), `akkhi` (eye), `acchi` (eye), `acci` (flame) and so on.

:::tip[Derivation]

|     | aṭṭhi + yo (🚻①⨂)     | rule |
| --- | --------------------- | ---- |
| →   | aṭṭhi + (yo→ni)       | 199 (§217) |
| →   | aṭṭh + (i→ī) + ni     | 147 (§88) |
| →   | **aṭṭhīni**           |      |

|     | aṭṭhi + yo (🚻①⨂)     | rule |
| --- | --------------------- | ---- |
| →   | aṭṭhi + ~~yo~~        | 146 (§118) |
| →   | aṭṭh + (i→ī)          | 147 (§88) |
| →   | **aṭṭhī**             |      |

:::

## `sukhakārī`

:::note[Inflection table of `sukhakārī`]

The forms of `sukhakārī` (bringing happiness), 🚻(sukhakārī), stated in the passage after rule 199, which has no rule of its own.

| | ⨀ | ⨂ |
| --- | --- | --- |
| ① | sukhakāri | sukhakārī, sukhakārīni |
| ⓪ | sukhakāri | sukhakārī, sukhakārīni |
| ② | sukhakārinaṃ, sukhakāriṃ | sukhakārī, sukhakārīni |

The rest as `daṇḍī`.

:::

> Ī kāranto napuṃsakaliṅgo sukhakārī saddo.

The neuter lemma ending in `ī` is the word `sukhakārī` ("bringing happiness").

> ‘‘Sukhakārī si’’[^56] itīdha anapuṃsakattābhāvā si smimpi ‘‘agho rassa’’miccādinā rassattaṃ, si lopo. Sukhakāri dānaṃ, sukhakārī sukhakārīni, he sukhakāri, he sukhakārī he sukhakārīni, sukhakārinaṃ sukhakāriṃ, sukhakārī sukhakārīni.

Here, in `sukhakārī` + `si`, since the word is not non-neuter, there is shortening even before `si` and `smiṃ` by [§84 (144): Agho rassamekavacanayosvapi ca](/kaccayana/2-namakappa/1-pathamakanda#m84) and the rest, and `si` is elided: `sukhakāri dānaṃ` ("a gift that brings happiness"); `sukhakārī`, `sukhakārīni`; `he sukhakāri`; `he sukhakārī`, `he sukhakārīni`; `sukhakārinaṃ`, `sukhakāriṃ`; `sukhakārī`, `sukhakārīni`.

:::tip[Derivation]

|     | sukhakārī + si (🚻①⨀)      | rule |
| --- | -------------------------- | ---- |
| →   | sukhakār + (ī→i) + si      | 144 (§84) |
| →   | sukhakāri + ~~si~~         | 74 (§220) |
| →   | **sukhakāri**              |      |

:::

> Sesaṃ daṇḍī saddasamaṃ. Evaṃ sīghayāyī ādīni.

The rest is the same as the word `daṇḍī`. In the same way `sīghayāyī` ("swift-going") and the like.

| | ⨀ | ⨂ |

> U kāranto napuṃsakaliṅgo āyu saddo. Tassa aṭṭhi saddasseva rūpanayo.

> Āyu, āyū āyūni, he āyu, he āyū he āyūni, āyuṃ, āyū āyūni, āyunā āyusāti manogaṇādittā siddhaṃ. Āyūhi āyūbhi, āyuno āyussa, āyūnamiccādi.

| | ⨀ | ⨂ |

## `gotrabhū`

:::note[Inflection table of `gotrabhū`]

| | ⨀ | ⨂ |
| --- | --- | --- |
| ① | gotrabhu | gotrabhū, gotrabhūni |
| ⓪ | gotrabhu | gotrabhū, gotrabhūni |

| ③ | gotrabhunā | |

> Ū kāranto na puṃsakaliṅgo gotrabhū saddo.

The neuter lemma ending in `ū` is the word `gotrabhū` ("become of the lineage").

> Gotrabhū si, napuṃsakattā rassattaṃ, si lopo. Gotrabhu cittaṃ, gotrabhū gotrabhūni, he gotrabhu, he gotrabhū he gotrabhūni, gotrabhuṃ, gotrabhū gotrabhūni, gotrabhunā iccādi pulliṅge abhibhū saddasamaṃ.

In `gotrabhū` + `si`, because the word is neuter there is shortening, and `si` is elided: `gotrabhu cittaṃ` ("the change-of-lineage mind"); `gotrabhū`, `gotrabhūni`; `he gotrabhu`; `he gotrabhū`, `he gotrabhūni`; `gotrabhuṃ`; `gotrabhū`, `gotrabhūni`; `gotrabhunā` and so on, the same as the word `abhibhū` in the masculine.

> Evaṃ abhibhū sayambhū dhammaññūādīni.

In the same way `abhibhū` (overlord), `sayambhū` (self-existent), `dhammaññū` (knower of the Dhamma) and the like.

## `cittago`

:::note[Inflection table of `cittago`]

The forms of `cittago` (having brindled cows), 🚻(cittago), stated in the passage after rule 199, which has no rule of its own.

| | ⨀ | ⨂ |
| --- | --- | --- |
| ① | cittagu | cittagū, cittagūni |

The rest as `āyu`.

:::

> O kāranto napuṃsakaliṅgo cittagosa ddo.

The neuter lemma ending in `o` is the word `cittago` ("having brindled cows").

> ‘‘Cittā gāvo assa kulassā’’ti atthe bahubbīhisamāse kate ‘‘saro rasso napuṃsake’’ti okārassa ṭhānappayatanāsannattā rassattamukāro, syā dyuppatti, si lopo. Cittagu kulaṃ, cittagū cittagūni iccādi āyu saddasamaṃ.

Once the `bahubbīhi` compound has been made in the sense "this family's cows are brindled" (`cittā gāvo assa kulassa`), the letter `o` is shortened by [§342 (337): Saro rasso napuṃsake](/kaccayana/4-samasakappa#m342), and its shortening is the letter `u`, since `u` is the nearest to it in place and effort of articulation (`ṭhānappayatana`); `si` and the rest arise, and `si` is elided: `cittagu kulaṃ` ("a family with brindled cows"); `cittagū`, `cittagūni` and so on, the same as the word `āyu`.

| →   | cittag + (o→u) + si     | 337 (§342) |
| →   | cittagu + ~~si~~        | 74 (§220) |
| →   | **cittagu**             |      |

:::

[Lemmas] ending in `o`.

> Cittaṃ kammañca assaddha-mathaṭṭhi sukhakāri ca; \
> Āyu gotrabhū dhammaññū, cittagūti napuṃsake.

`citta` and `kamma`, `assaddha`, then `aṭṭhi` and `sukhakāri`, \
`āyu`, `gotrabhū`, `dhammaññū`, `cittagu` — thus it is in the neuter.

> _Napuṃsakaliṅgaṃ niṭṭhitaṃ._

The neuter gender is finished.
